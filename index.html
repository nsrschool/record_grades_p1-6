📖 คู่มือการใช้งาน

1. หน้าแรก — ภาพรวมจำนวนนักเรียนและสรุปรายชั้น
2. รายงานสรุป — ค้นหา/กรองตามชั้น สั่งพิมพ์ หรือส่งออก Excel
3. ตั้งค่าระบบ — ข้อมูลสถานศึกษา โลโก้/ลายเซ็น และจัดการรายชื่อนักเรียน
4. สำรอง/นำเข้า/ล้างข้อมูล — ปุ่มด้านบนขวา (.json) • ระบบยังสำรองอัตโนมัติรายวันลง Drive

⚙️ วิธีติดตั้ง (Sheets + Edge)

1. สร้าง Google Sheet ใหม่ → ส่วนขยาย → Apps Script → วางโค้ด Code.gs
2. Deploy → New deployment → Web app • Execute as: Me • Who has access: Anyone → คัดลอก URL (/exec)
3. เปิดไฟล์ index.html แก้ window.WEB_APP_URL บนสุดของไฟล์ ให้เป็น URL ที่ได้
4. อัปโหลด index.html ขึ้น GitHub Pages (หรือ Cloudflare Pages) → ใช้ URL ของ Pages เข้าระบบ
5. ใน Google Sheets เมนู ระบบนักเรียน → ⏰ เปิดสำรองอัตโนมัติรายวัน (ครั้งเดียว)
💡 แก้ Code.gs เมื่อไร ต้อง Deploy → Manage deployments → ✏️ → New version ทุกครั้ง • แก้ index.html แค่อัปไฟล์ใหม่ขึ้น Pages
